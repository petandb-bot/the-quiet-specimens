# Elsewhere — B3 Living Territories

住民は一つの場所から出発し、近くの構造物を調べ、気に入った場所をもう一度訪れる。出会ったときだけ相手に注意を向け、短い動作を残してそれぞれの生活に戻る。

## 場所と性格

各住民は Home、Preferred Area、Exploration Range、Resting Place を持つ。Curiosity と Caution には既存の Genome を使う。Activity は歩調・忍耐・シードから、Social Tendency はシードから導出する。地形、遮蔽、距離、最近の訪問を候補地点の採点に使う。好奇心が強い個体や VESSEL は行動半径が広くなりやすい。

最近の訪問は最大9件、寿命は135シミュレーション秒。近接した地点は新しい訪問で置き換える。関心を持った構造物を覚え、直近で訪れた場所には一時的に低い優先度を付ける。場所の記憶や相互作用の状態は Genome から分離し、地形を変更すると作り直す。

## 行動

| 場面 | 行動 |
| --- | --- |
| 探索 | 好みの地域または現在地の周囲から、訪問間隔と地形条件に合う目的地を選ぶ |
| 帰巣 | 生活圏の外縁を越えたときや、長く出歩いたあとに Home へ向かう |
| 休息 | 活動量に応じて休息地点へ戻る。ゆっくり休む個体や、短い休止を挟んで次の探索に進む個体がいる |
| 調査・集まり | 近くのランドマークへ寄り、身構えや固有のジェスチャーを見せる。同じ場所を好む個体は少し離れた地点に集まることがある |

HINGE は平らな場所を好み、斜面や障害物の手前で速度を落とす。VESSEL は開いた場所を好み、漂う高さと、出会ったときに見える内部の動きが変わる。RELAY は窪地や物陰を休息地に選びやすく、狭い場所では節の間隔を詰める。従来のジェスチャーには既存の予備動作と回復を使う。

## 出会いと模倣

**Encounter** では速度を落として相手を向くか、距離を取る。**Follow** は動いている相手と少し間隔を空け、約3〜6秒で解ける。**Imitation** は近くの自然発生したジェスチャーを約0.5〜1.2秒後に、相手の体型に合う動作で弱く繰り返す。模倣と手動再生のジェスチャーは模倣の発生源から除く。

同じ個体やペアにはクールダウンを設ける。対象が離れたり、庭園から外されたりしたときは反応を解除する。最近のイベントは最大12件・100秒。行き先の選択は個体が行い、全員を集める演出用のタイマーは置かない。

移動は1/60秒の固定刻みで進み、相互作用の候補は約0.3秒ごとに調べる。鑑賞カメラや音響の時計とは別に進む。Inspect / Action の間も住民のシミュレーションは進行する。音響は選択中の1体が持つ音色と周期を使う。
