# Elsewhere — B1/B2 preview

- 地上の行動範囲は60×60、描画地形は240×240。台座を撤去し、透視投影と遠景霧で視界の外へ地形を伸ばす。
- Rolling Field / Terraces / Hollow Land。Seed、Elevation、Roughness。描画と接地は同一の三角形補間高を参照。Terraces は急な壁ではなく緩和された段差。
- 8つのランドマークと9つの初期活動地点。従来の造形とジェスチャーを維持し、現在位置周辺から長い探索目標を選ぶ。高低差で地上型の速度を調整。地形変更は個体を維持して位置を再初期化する。
- Landscape / Wander / Follow。Inspect / Action は継続。Follow は選択中の住民がいない場合 Landscape に戻る。
- Photo backdrop は静止画像を遠景としてアスペクト比を保って切り抜き、下部の代表色で霧と地面を調整する。20MB、最大2048pxへ縮小。元画像は送信・永続保存しない。背景写真は環境マップとしては使わない。
- 既存音響、旧版、IndexedDB は未変更。最大9体、選択中1体の発音。
- 今回は天候・昼夜、相互作用の深化、経路探索、オブジェクト編集、ワールド永続保存を実装しない。
- 地形の接地はルート位置で行うため、長い個体の全接点が斜面に正確に接地する保証はない。障害物回避は簡易方式のまま。
- 追加テスト: tests/elsewhere.test.ts。実行環境で GitHub への直接アクセスができなかったため、npm test/build、WebGL実描画、モバイル実機検証は未実施。マージ前に実行すること。
